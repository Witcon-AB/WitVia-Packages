WitVia för Linux ARM64

Detta är Witcons signerade APT-repository för WitVia Edge på Debian 13 / Raspberry Pi OS Trixie, ARM64.

curl -fLO https://witcon-ab.github.io/WitVia-Packages/install-from-apt.sh
less install-from-apt.sh
sudo bash install-from-apt.sh

Installationsskriptet accepterar endast arm64. Läs alltid skriptet innan det körs som root.
